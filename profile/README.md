  # Vowels Group

  We build open-source tools for decentralized, peer-to-peer networks.

  Our work centers on **eIOU**: a credit network where independently operated nodes record IOUs and route transactions
  through trusted contacts, without a blockchain or shared global ledger. We also build integrations that connect this
  network to practical services, including AI inference.

  ## Explore eIOU

  Visit **[eiou.org](https://eiou.org)** to learn about our projects, find setup guides, and get in touch.

  ## Our projects

  ### eIOU Docker

  Run your own eIOU node with Docker, with a web dashboard, command-line tools, and REST API for managing contacts,
  transactions, and node settings.

  **[View repository on GitLab →](https://gitlab.com/eiou-org/eiou-docker)**

  ### eIOU MCP Passthrough

  Connect MCP clients to model inference through an eIOU node. Use configured model APIs, inference infrastructure you
  operate, or participating eIOU providers, with usage tracking and billing through the node.

  **[View repository on GitLab →](https://gitlab.com/eiou-org/eiou-plugin-mcp-passthrough)**

  ## Get involved

  Development and code review happen on **[GitLab](https://gitlab.com/eiou-org)**. Contributions, bug reports, and
  documentation improvements are welcome—start with the relevant repository.

  eIOU is in open alpha and under active development.
